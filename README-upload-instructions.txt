個人網頁上傳說明
==================

這個資料夾裡有兩個檔案：

1. index.html   → 你的個人履歷網頁本體
2. robots.txt   → 讓 Google 等搜尋引擎不收錄這個網頁（只有拿到連結的人才看得到）

上傳步驟（使用 GitHub Pages，跟你之前做儀表板的方法一樣）：

1. 登入 GitHub，開一個新的 public repository
   （建議取一個中性的名字，例如 vita-lee-resume）

2. 把這兩個檔案「index.html」和「robots.txt」一起拖曳上傳到這個 repository
   （兩個檔案要放在同一層，不要放進子資料夾）

3. 進入這個 repository 的 Settings → Pages

4. Source 選擇「Deploy from a branch」
   Branch 選「main」，資料夾選「/ (root)」，按 Save

5. 等待約 1 分鐘，重新整理 Settings → Pages 這頁
   上方會出現一個綠色框，顯示你的網址，例如：
   https://你的帳號.github.io/repo名稱/

6. 打開這個網址，確認：
   - 自傳、成就、工作經歷都正常顯示
   - 九個作品成果的連結都能點開

這個網址就是你可以放進履歷、名片、求職信裡，
提供給企業瀏覽的個人網頁連結。
